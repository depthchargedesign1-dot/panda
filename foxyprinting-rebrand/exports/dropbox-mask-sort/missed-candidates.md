# Other Dropbox folders that may hold masks missing from the clean set (quick scan, 5 Oct 2026)

Found with read-only Dropbox searches for "face mask", "facemasks", "celebrity masks" and "masks" (folder names), then a read-only listing or a size check of each folder. Nothing was opened, moved or changed. Not analysed in depth yet.

"Names not in the tidy set" = image file names in that folder whose normalised name (same rules as `plan.csv`) does not appear anywhere in `/2019 TIDY - CELEBRITY FACEMASKS FINAL 7200 IMAGES`. It is a rough guide: spelling differences and names with the show in them inflate it a little, and SKU-numbered files cannot be compared by name at all. Listings are saved in `missed-raw/*.jsonl` (path and size only).
