# Celebrity face masks: new descriptions, SEO titles and meta descriptions (2 Oct 2026)

Generated by `tools/mask_copy.py` from the live listings, using facts from the "Face masks" sheet in `plan/product-facts.md`.

**What each listing gets:**
- a unique description of 235–288 words, written around the star's name and their field (sport, TV, music and so on);
- one H2 and the house layout;
- the celebrity disclaimer as the last block, which also names the show where there is one;
- an SEO title (≤60 characters) and a meta description (140–155 characters).

Titles, prices and images are not touched.

| File | Count |
|---|---|
| `masks-00-TEST.csv` | 3 products, for the test import |
| `masks-01.csv` + `masks-02.csv` | 5,760 single-option masks |
| `masks-api-multivariant.json` | 5 masks with several options. Already applied through the API. |
| `masks-manual-review.csv` | 1,196 listings left out: packs, couples, custom/personalised masks, characters, and titles where the person's name isn't clear. These need a second pass. |
| `masks-preview.csv` | the name and category used for every listing, so you can check them |

## Import (owner, about 5 minutes)
1. Shopify admin → Products → Import → `masks-00-TEST.csv`, with **"Overwrite products with matching handles"** ticked.
2. Open those 3 products. The description and the SEO section should be new. Check that the title, price, images and options are unchanged.
3. Import `masks-01.csv`, then `masks-02.csv`.
