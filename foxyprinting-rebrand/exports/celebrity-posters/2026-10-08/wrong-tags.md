## Safe fix (proposed – needs the owner's OK; nothing done yet)

The risk is the poster size/frame picker: if Infinite Options (or another app) finds these posters through the
"All Posters – For size options" collection, removing "Other Console Posters" would make the size choices vanish from
9,475 posters. So do it in this order:

1. **Owner checks the app (2 minutes):** Apps › Infinite Options › the poster size option set › Conditions. Note
   whether it targets the collection "All Posters - For size options" or a tag.
2. **Add a neutral tag first** – `poster-size-options` – to all 9,475 posters (tagsAdd, nothing removed).
3. **Keep the size collection working:** add the rule *Tag is equal to `poster-size-options`* to
   `all-posters-for-size-options` (it is an OR collection, so nothing drops out). If the app uses a tag condition,
   add `poster-size-options` there too.
4. Re-read: `all-posters-for-size-options` must still hold 13,786 products; open 2–3 posters on the site and check
   the size picker still shows.
5. **Then remove `Other Console Posters`** from the 9,475 celebrity posters (keep it on the real Intellivision, Neo Geo,
   Jaguar CD, Amiga CD32 and Odyssey game posters). Note: 427 other products without "Printed Signature" in the title
   also carry it; about half are game posters, but ~200 are team-player prints, "Posters, Prints & Visual Artwork" and
   "Signed Athletics Prints"-type items that need the same treatment. ALL RETRO GAMING then drops from 13,786 to
   roughly 4,100 real retro items; the size collection keeps everyone through the new tag.
6. Remove `Signed Athletics Prints`, `SignedAutographedPrint` and the 30 memorabilia/limited-edition/collectible tags
   (no rule uses them). Keep `Display Poster Print` or swap it for `poster-size-options` – owner's choice.
7. Fix the 20 F1 name tags (each poster keeps only its own driver's name) and the Leclerc "Lewis Hamilton" tag.
8. Later: change product type "Signed Athletics Prints" on the 579 non-athletes to the right type (e.g. "Footballer
   Posters"); the new sub-collections already catch them through their `cp-` tags, so nothing moves.

About 19,000 tag edits in total – done through the API in batches (no CSV needed), roughly an hour of runs.
