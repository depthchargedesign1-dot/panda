# eBay Personalise box: text per product

These match the website's personalisation fields (`foxy.personalise_fields`, 9 Oct 2026). eBay's Personalise box takes text only, so photos are sent through eBay messages after purchase.

The Personalise instructions for each listing are below. Paste the line for that product, then the photo sentence.

| Listing | Ask the buyer to type in the Personalise box |
|---|---|
| Personalised Photo Face Masks (your own face) | Up to 3 faces. Name (optional). How many of each face. Notes for our designer. |
| Stag Do Face Masks | Groom’s name. Up to 3 faces. How many of each face. Notes for our designer. |
| Hen Party Face Masks | Bride’s name. Up to 3 faces. How many of each face. Notes for our designer. |
| Personalised Birthday Face Masks | Name. Age. Up to 3 faces. How many of each face. Notes for our designer. |
| Wedding Photo Booth Face Masks | Couple’s names. Bride’s and groom’s photos (up to 4 faces). How many of each face. Notes for our designer. |
| Leaving Do & Retirement Face Masks | Name. Up to 3 faces. How many of each face. Notes for our designer. |
| Office & Christmas Party Face Masks | Team or company name (optional). Up to 3 faces. How many of each face. Notes for our designer. |

Photo sentence, the same on every one: **"After you buy, send your photo(s) to us through eBay messages: a clear, front-facing photo works best. We'll message you if we need a better one."**

Item specific: `Personalise` = `Yes`. Character limit: use the eBay maximum.
